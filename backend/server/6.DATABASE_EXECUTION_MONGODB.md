# 6. Database Execution (MongoDB with Prisma)

If you are following a tutorial or video that uses MySQL/PostgreSQL, you will often see them running `.sql` scripts (Data Definition Language like `CREATE TABLE`) using a VS Code Database Client.

**However, since Mahbub Shop is built with MongoDB (NoSQL) and Prisma, the workflow is fundamentally different.**

## Why is there no SQL script for MongoDB?
MongoDB is a **schema-less** NoSQL database. It does not use tables, columns, or strict SQL structures. Instead, it stores data as JSON-like documents (BSON) inside "Collections". 
Because of this, MongoDB does not need a `CREATE TABLE` command. Collections are created automatically the exact moment you insert the first piece of data into them.

## How Prisma Handles MongoDB

Prisma bridges the gap by providing a strict schema (`schema.prisma`) on top of MongoDB at the application level. To "execute" your database schema in MongoDB with Prisma, you do not run SQL. Instead, you use Prisma CLI commands.

### Step 1: Generate the Prisma Client
Whenever you update your `schema.prisma` file, you must tell Prisma to regenerate the Javascript/TypeScript client so your application knows about the new models.

```bash
npx prisma generate
```

### Step 2: Push the Schema to MongoDB
Unlike SQL databases where you use `npx prisma migrate dev`, for MongoDB you use the `db push` command. This command ensures that any required indexes (like `@unique` fields) are created in your MongoDB database.

```bash
npx prisma db push
```

### Step 3: View your Data
Instead of using a generic SQL Database Client in VS Code, you have two excellent options to view and manage your MongoDB data:

1. **Prisma Studio (Recommended):**
   Prisma comes with a built-in GUI to view your data. Run this command in your terminal:
   ```bash
   npx prisma studio
   ```
   This will open a beautiful interface in your browser (`http://localhost:5555`) where you can see all your MongoDB collections, add data, and edit records.

2. **MongoDB Compass:**
   You can download MongoDB Compass (the official GUI) and connect it to your `DATABASE_URL` (found in your `.env` file) to directly manage the raw NoSQL database.

## Summary of the NoSQL Workflow
- No `.sql` files needed.
- No `CREATE TABLE` commands.
- Run `npx prisma generate` to update code.
- Run `npx prisma db push` to sync indexes.
- Run `npx prisma studio` to view data.
