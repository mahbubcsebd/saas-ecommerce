# 7. Testing with Dummy Data (Seeding)

To easily test the frontend and backend without having to manually insert products, categories, users, or orders one by one, a **Database Seeder** has already been set up in this project.

The seeder automatically inserts comprehensive dummy data into your MongoDB database, including User accounts, Products with Variants, Orders, and Settings.

## How the Seeder Works

## How the Seeder Works

The logic for seeding is modularized and located at:
`backend/server/prisma/seeds/`

Each schema domain has its own dedicated seed file (`users.seed.js`, `products.seed.js`, etc.).

---

## Commands to Run the Seeders

Open your terminal, navigate to the `backend/server` directory, and run the following commands based on your needs:

### 1. Run All Seeds
To insert all dummy data sequentially:
```bash
npm run db:seed
```

### 2. Run Individual Seeds
If you only want to seed a specific table (e.g., just users or products):
```bash
npm run db:seed:users
npm run db:seed:categories
npm run db:seed:products
npm run db:seed:expenses
```

### 3. Reset & Seed (Fresh Start)
If you want to wipe the database clean and re-insert fresh dummy data:
```bash
npm run db:reset
```
