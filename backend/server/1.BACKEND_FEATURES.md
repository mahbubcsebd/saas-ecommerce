# Mahbub Shop — Backend Features & Requirements

> Full-stack SaaS E-commerce engine built with Node.js, Express, Prisma (MongoDB), Redis, and Socket.io.

---

## 1. Authentication & User Management

- **Registration**: Self-registration with optional email verification (configurable via `ENFORCE_EMAIL_VERIFICATION`).
- **Login**: Supports login via Email, Username, or Phone number.
- **JWT Authentication**: Access Token (24h) + Refresh Token (7d) with HTTP-only secure cookies.
- **Refresh Token Rotation**: Old tokens are invalidated on every refresh for security.
- **Email Verification**: Token-based email verification with expiry.
- **Password Reset**: Forgot password flow with secure email link (1-hour expiry).
- **Staff Invitation System**: Admin can invite staff via email → staff sets their own password via token link.
- **Guest Cart Merge**: On login, guest cart items are automatically merged with the user's existing cart.
- **Login Notifications**: Every login triggers a notification; admin/staff logins are broadcast to other admins.

### Roles & Permissions

- **Built-in Roles**: `SUPER_ADMIN`, `ADMIN`, `MANAGER`, `STAFF`, `STAFFER`, `CUSTOMER`.
- **Custom Roles**: Create dynamic roles with granular permission strings (e.g., `product.update`, `order.manage`).
- **User Statuses**: `PENDING`, `ACTIVE`, `INACTIVE`, `SUSPENDED`.
- **Customer Groups**: Group customers for targeted discounts (e.g., VIP, Wholesale).

### Security

- **Rate Limiting** (`express-rate-limit`): Brute force & DDoS protection.
- **Helmet**: Secure HTTP headers.
- **Mongo Sanitize** (`express-mongo-sanitize`): NoSQL injection prevention.
- **XSS Protection** (`xss`): Input sanitization.
- **CORS**: Configurable cross-origin resource sharing.

## 2. Product Management

- **Core Fields**: Name, auto-generated slug, rich description, base price, selling price, cost price.
- **Multi-Image Gallery**: Multiple images per product, stored on Cloudinary with Sharp optimization.
- **SKU & Barcode**: Unique identifiers for inventory tracking.
- **Product Status**: `DRAFT`, `PUBLISHED`, `ARCHIVED`.
- **Weight & Dimensions**: For shipping calculation (weight, length, width, height).
- **Home Page Control**: `isHomeShown` and `homeOrder` fields for curated homepage display.
- **Flags**: `isNewArrival`, `isFeatured`, `isFreeShipping`, `isPreOrder`.
- **Warranty**: Optional warranty text per product.
- **Analytics Counters**: `viewCount`, `soldCount`, `numReviews`, `rating`.

### Variant System

- Each variant has its own SKU, barcode, stock, pricing overrides (base/selling/cost), and images.
- Attributes stored as JSON (e.g., `{ color: "Red", size: "XL" }`).
- Variant-level overrides for free shipping, pre-order, and warranty.

### SEO Metadata

- Per-product: `metaTitle`, `metaDescription`, `metaKeywords`, `ogImage`.
- Per-category: Same SEO fields with hierarchical structure.
- AI-powered SEO content generation for categories (via Gemini).

### Categories

- **Hierarchical**: Parent-child relationships with unlimited depth.
- **Category Features**: Image, icon, `isHomeShown`, display order, active/inactive toggle.
- **SEO**: Per-category meta tags.

### Reviews

- Customer star ratings (1-5) with text comments and image uploads.
- **Moderation**: `PENDING`, `APPROVED`, `REJECTED` statuses.
- Admin can reply to reviews (`adminReply`).
- Flagging system for inappropriate content.

## 3. Inventory & Supply Chain

### Stock Tracking

- Real-time stock for both products and individual variants.
- `trackInventory` toggle per product.
- `minStockLevel` / `lowStockAlert` thresholds for automated alerts.

### Stock Movements

- Full audit trail of every stock change with:
    - Type: `PURCHASE`, `SALE`, `RETURN`, `ADJUSTMENT`, `DAMAGE`, `PURCHASE_RETURN`.
    - `previousQty` → `newQty` tracking.
    - Linked to orders, purchases, suppliers, and staff actions.

### Supplier Management

- Supplier profiles: name, contact person, email, phone, address.
- **Due Balance Tracking**: Running balance per supplier.
- **Supplier Transactions**: Ledger of all financial movements (Purchase, Return, Payment, Adjustment) with `balanceAfter`.

### Purchase Orders

- Create purchase orders linked to suppliers with line items (product, variant, quantity, unit cost).
- Status: `PENDING`, `RECEIVED`, `CANCELLED`.
- Auto-generates stock movements on receipt.

### Purchase Returns

- Return stock to suppliers with item-level tracking.
- Auto-adjusts supplier balance and stock levels.

### Supplier Payments

- Record payments with method (Cash, Bank, bKash), reference, and notes.
- Each payment creates a supplier transaction entry.

### Damage & Loss Reporting

- Log damaged/expired/stolen/lost items with reason codes.
- Tracks loss amount (quantity × cost price).
- Links to specific products, variants, and reporting staff.

---

## 4. Cart & Checkout

- **Authenticated & Guest Carts**: Supports both logged-in users and session-based guest carts.
- **Cart Items**: Product + optional variant, quantity, unit price snapshot, and discount.
- **Coupon Application**: Apply coupon codes at cart level with discount calculation.
- **Abandoned Cart Tracking**:
    - `recoveryEmailSentAt`, `recoveryEmailCount`, `isRecovered` fields.
    - Automated recovery email with product details and "Complete Your Purchase" CTA.
- **Buy Now**: Direct single-item purchase bypassing the cart.

---

## 5. Orders & Invoicing

### Order System

- **Multi-Source**: `ONLINE`, `POS`, `MARKETPLACE`.
- **Order Number**: Auto-generated (e.g., `ORD-20260509-A1B2C`).
- **Guest Orders**: Supports guest checkout with `guestInfo` (name, email, phone).
- **POS Features**: Walk-in customer name/phone, tendered amount, change calculation, instant `COMPLETED` status.

### Order Lifecycle

- Statuses: `PENDING` → `PROCESSING` → `SHIPPED` → `DELIVERED` → `COMPLETED` / `CANCELLED` / `REFUNDED`.
- **Bulk Status Update**: Admin can update multiple orders at once.
- **Cancellation**: Automatically reverts stock and soldCount.
- **Tracking**: `trackingNumber`, `shippedAt`, `deliveredAt` timestamps.

### Financial Breakdown

- Subtotal, discount (percentage/flat), VAT/tax, shipping cost, COD extra charge, and total.
- Applied coupon tracking with discount amount.

### Payment & Due Management

- Methods: `CASH`, `BKASH`, `NAGAD`, `CARD`, `ONLINE`, `COD`.
- Statuses: `PENDING`, `UNPAID`, `PARTIAL`, `PAID`, `REFUNDED`, `FAILED`.
- **Due Collection**: Track partial payments for an order. System automatically computes `dueAmount` and records multiple installment payments (`OrderPayment` model).
- Payment gateway settings: bKash, Nagad, Stripe, PayPal, SSLCommerz (all configurable from admin).

### Invoicing

- Auto-generated invoice numbers (e.g., `INV-20260509-X1Y2Z3`).
- Professional PDF generation via PDFKit.
- Email invoice with PDF attachment.
- Invoice statuses: `PENDING`, `PAID`, `OVERDUE`, `CANCELLED`.

### Return Management (RMA)

- Customers submit return requests with reason, quantity, and proof images.
- RMA ID tracking (e.g., `RET-001`).
- Admin approval workflow: `PENDING` → `APPROVED` / `REJECTED` → `REFUNDED`.
- Automatic stock reconciliation on approval.

## 6. Discounts & Promotions

### Discount Engine

- **Types**: `PERCENTAGE`, `FLAT`, `BUY_X_GET_Y`, `FREE_SHIPPING`.
- **Targeting**: Apply to specific Products, Categories, Brands, Cart, or Shipping.
- **Conditions**: Minimum order value, maximum discount cap, usage limits (total + per user).
- **Advanced Targeting**: Allowed countries, excluded products, allowed user IDs, allowed customer groups, new users only.
- **Priority & Stacking**: Priority ordering and stackable discount support.
- **Usage Tracking**: `DiscountUsage` model tracks who used what discount on which order.

### Coupon System

- Unique coupon codes with all discount features.
- Validation at checkout with per-user usage limits.

### Flash Sales

- Scheduled events with start/end dates.
- Per-product flash pricing with stock limits.
- Tracks `soldCount` per flash sale product.

## 7. Shipping & Logistics

### Shipping Zones

- Define zones by country (ISO codes) and regions.
- Priority-based zone matching.

### Shipping Rates

- **Calculation Types**: `FLAT`, `WEIGHT_BASED`, `ORDER_VALUE`, `TABLE_RATE`.
- Configurable per zone: flat rate, per-kg rate, free shipping threshold.
- Estimated delivery days.
- Linked to specific couriers.

### Courier Management

- Courier profiles: name, code, logo, website.
- Integration config: API credentials, tracking URL template, tracking type (`POLLING`, `WEBHOOK`, `MANUAL`).
- Supported countries and service levels (COD, NEXT_DAY, FRAGILE, etc.).

### Packaging

- Standard packaging options with dimensions, weight limits, and costs.

### Shipping Settings

- Global: Enable/disable shipping, default zone, free shipping threshold.
- Calculation method: `ZONE_BASED`, `FLAT_RATE`, `REAL_TIME`.
- Real-time API provider support (Shippo, EasyPost).

## 8. Communication

### Live Chat (Socket.io)

- Real-time bidirectional messaging.
- Conversation types: `SUPPORT`, `ORDER`, `GENERAL`.
- Conversation statuses: `OPEN`, `IN_PROGRESS`, `RESOLVED`, `CLOSED`.
- Message features: File attachments, reply threading, emoji reactions, edit/delete, read receipts.
- Admin assignment: Conversations can be assigned to specific staff.
- Online/offline status and last seen tracking.

### Notification System

- **60+ notification types** covering:
    - Customer: Order updates, payment status, wishlist alerts, price drops, birthday offers, etc.
    - Admin: New orders, low stock, suspicious activity, daily reports, etc.
- In-app real-time delivery via Socket.io.
- Read/unread status tracking.

### Email System (Nodemailer)

- Dynamic SMTP configuration from database (fallback to env vars).
- **Transactional Emails**: Welcome, verification, password reset, order confirmation, invoice PDF attachment.
- **Custom Emails**: Admin can send free-form emails to users.
- **Campaign Emails**: Bulk sending with variable substitution and CSS inlining (via Juice).
- **Abandoned Cart Emails**: Automated recovery emails with product listings.
- **Email Templates**: Stored in DB with GrapesJS builder support, variable placeholders, and active/inactive toggle.
- **Configurable Toggles**: Enable/disable order confirmation, shipping update, delivery confirm, and abandoned cart emails.

### SMS (Twilio)

- Configurable gateway (Twilio, MSG91, etc.).
- Toggles for order confirmation, shipping update, delivery confirm, and OTP.

## 14. System Settings

All settings are stored in dedicated database models for admin-level configuration:

| Setting | What It Controls |
| :--- | :--- |
| **GeneralSetting** | Site name, tagline, logos, maintenance mode, timezone, currency, date/time format, shop type |
| **CurrencySetting** | Currency code/symbol, decimal formatting, multi-currency support, auto-update rates |
| **ContactSetting** | Email, phone, WhatsApp, address, social links (FB, IG, YouTube, Twitter, LinkedIn, TikTok, Pinterest), business hours |
| **SeoSetting** | Global meta tags, OG tags, Google Analytics, Facebook Pixel, GTM, site verification, robots indexing |
| **EmailSetting** | SMTP config, sender info, email notification toggles |
| **SmsSetting** | SMS gateway config, notification toggles |
| **LegalSetting** | Terms, privacy policy, return policy, shipping policy |
| **AppearanceSetting** | Colors, fonts, header/footer style, homepage section toggles, custom CSS/JS injection |
| **PaymentSetting** | COD, bKash, Nagad, Stripe, PayPal, SSLCommerz — each with enable/disable and credentials |
| **OrderSetting** | Min/max order amount, prefixes, guest checkout, backorder rules, low stock threshold, auto-cancel unpaid, return policy days |
| **TaxSetting** | Enable/disable tax, VAT number, tax-inclusive pricing |
| **ShippingSetting** | Enable/disable, default zone, free shipping threshold, calculation method, real-time API |
| **CompanySetting** | Company name, logo, address, tax ID, invoice terms |
| **IntegrationSetting** | Analytics IDs, third-party configs |
